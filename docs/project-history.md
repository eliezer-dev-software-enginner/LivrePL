# Historico do projeto

O LivrePL foi idealizado e conduzido por **Eliezer Dev** ([GitHub](https://github.com/eliezer-dev-software-enginner)), que definiu o escopo, validou cada etapa e decidiu as evolucoes da linguagem.

O levantamento inicial de requisitos e o desenho da arquitetura de lexer, parser, AST e interpretador tree-walking foram elaborados em conversas iterativas com ferramentas de desenvolvimento assistido. Os documentos tecnicos em `docs/` registram o desenho e os limites de cada etapa. A implementacao Python consolidou esses desenhos em `lexer.py`, `parser.py`, `interpreter.py` e nos demais modulos do runtime.

Este historico fica na documentacao interna para manter o README concentrado no produto, instalacao e uso observavel.
